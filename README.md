# HIRE-ANHAF

A full-featured Telegram Hire Bot and Admin Web Dashboard system with crypto payment verification, real-time live events, and automated order handling.

## Features

- **Telegram Hire Bot**: Handles hiring requests, order processing, notifications, and crypto payment verification.
- **Admin Web Dashboard**: Live web panel to monitor orders, view statistics, manage settings, and receive real-time websocket updates.
- **Crypto Verification Engine**: Multi-network cryptocurrency verification (Bitcoin, Ethereum, BSC, Tron).
- **Docker Compose Ready**: One-click deployment for Coolify, VPS, or local docker setup.
